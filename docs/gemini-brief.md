# 정읍 지금 — 제미나이에게 전달하는 작업 현황 (2026-11-20, 앱 v81)

> 목적: 지금까지 만든 것을 알려 주고, **디자인·UI 개편 방향(시안·색·화면 구성)** 을 잡아 달라는 요청.
> 코드는 쓰지 말고 방향·색·화면 구성·문구 위주로 제안해 주세요. 코드는 다른 도구(Claude)가 반영합니다.

## 1. 서비스 개요
- 이름: **정읍 지금** (전라북도 정읍시 전용 지도 + 실시간 제보 + 커뮤니티)
- 주소: https://dujin986-bit.github.io/jeongeup-map/ (GitHub Pages)
- 만든 사람: 정읍의 공인중개사 1인. 폰(갤럭시 폴드8, 삼성 인터넷/크롬)과 태블릿 위주 사용.
- 대상: 정읍 시민·지인 → 인스타/스레드 링크로 확산 → 이후 수익화(실시간 정보+커뮤니티 먼저, 부동산 기능은 나중). 고령 사용자도 쓰므로 **큰 글씨·단순함**이 중요.
- 기술: 순수 HTML/JS/CSS, MapLibre GL JS(OpenFreeMap 3D), Supabase(DB·로그인·저장소·Edge Function), PWA(설치형), 웹푸시.

## 2. 현재 있는 화면과 기능
**지도 메인**
- 3D 건물(낮/밤 색 다름), 아파트 창문 패턴, 도로·가로등, 날씨 효과(비·눈), 야간 모드
- 지도에는 **음식점·카페·술집만** 표시(상가 과다 문제로 정리). 점을 누르면 정보창.
- 🏛 관공서 레이어(시청·주민센터 등 일부), 내장산 랜드마크
- 상단: 1줄(이름·검색·필터·제보·새로고침), 2줄 도구 칩(가로 스크롤). 검색창은 누르면 전체 폭으로 확대.
- 공지 띠(긴급=빨강, 일반=파랑)

**제보**
- 길게 누르기/＋제보하기 → 위치 맞추기 → 분류(교통·행사·웨이팅·사건사고·생활정보) 입력 → 관리자 승인 후 노출
- 제보 종류별 자동 만료(배지에 남은 시간 표시)
- 제보 선택창에 "🛠 가게 정보 수정", "➕ 없는 가게 알려주기"

**커뮤니티**
- 다크 카드 UI, 소식 탭 + 알바·중고·부동산(준비 중)
- 오늘의 맛집 TOP 3 투표(하루 1표), 퍼센트 막대
- 👍/👎, "정보가 틀렸어요" 수정 요청

**관리자(admin.html, 사장님 전용)**
- 제보 승인/숨김/삭제, 공지 작성(+손님에게 푸시 알림 체크), 날씨 수동 설정, 편집기록 되돌리기, 수정요청 확인
- 새 제보가 들어오면 **관리자 폰·PC로 푸시 알림**(방금 완성)

## 3. 이번 세션에서 한 일 (v66 → v81)
- 커뮤니티 다크 카드 UI, 제보 만료 배지 타이머
- 뒤로가기(앱이 바로 꺼지는 문제) 수정
- 관공서 레이어, 지도 표시를 음식점·카페·술집 위주로 축소, 터치 영역 확대
- `?public=1` 손님 시점 보기, 로컬 개발용 .bat 파일
- **웹푸시 알림 완성**: VAPID, 서비스워커, Supabase Edge Function(send-push), DB 트리거 → 새 제보 시 관리자 알림. PC(Edge·Chrome)와 폰(Chrome)에서 수신 확인.
- 해결한 문제: DB 권한(service_role), 키 형식 오류, 웹훅 비밀값 불일치, 삼성 인터넷은 알림 허용창 미지원(→ 관리자는 Chrome 사용)

## 4. 디자인상 현재 불만·한계 (사용자와 확인 필요)
- 화면마다 색·카드 스타일이 통일돼 있지 않음(지도=밝은 UI, 커뮤니티=다크 카드, 관리자=별도)
- 상단 칩이 많아 복잡해 보임
- 맛집 투표 1등 막대 색(금색) 미완성
- 정읍만의 정체성(내장산 단풍, 지역색)이 약함
- 삼성 인터넷 사용자는 푸시 알림 불가 → 손님 알림은 "앱 설치(홈 화면 추가)" 안내 필요

## 5. 제미나이에게 요청하고 싶은 것
1. **전체 디자인 방향** 2~3안 (색 팔레트, 폰트 분위기, 카드/칩/버튼 스타일). 지금 톤을 유지하는 안과 크게 바꾸는 안을 각각.
2. **지도 메인 화면 구성**: 상단 영역 단순화, 하단 탐색(탭/버튼) 배치 제안
3. **커뮤니티·제보 화면**: 카드 레이아웃, 분류별 색·아이콘 체계(교통·행사·웨이팅·사건사고·생활정보)
4. **고령자 친화**: 글자 크기, 터치 영역, 대비
5. **정읍 정체성**: 내장산·단풍·정읍사 등을 색/로고/아이콘에 녹이는 방법
6. 가능하면 **화면 와이어프레임 설명**(글로 구조 설명) — 이미지는 참고용

## 6. 제약 조건
- 순수 HTML/CSS/JS(프레임워크 없음), 무료 호스팅(GitHub Pages) 유지
- 지도는 MapLibre 위에 UI가 올라가는 구조 → 지도를 가리지 않는 가벼운 UI
- 성능: 폰에서 버벅이지 않게 무거운 효과(큰 블러, 많은 애니메이션) 지양
- 비밀 키·개인정보는 이 문서에 없음. 요청에도 포함하지 말 것.
